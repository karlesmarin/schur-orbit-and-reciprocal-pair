# 🧮 Part II — the gluing term, and the census of the defect

**Thirty-one scripts, each with its archived output. Python 3 standard library and `numpy`,
nothing to install. Exact integers wherever a count is exact.**

Part I showed that the ring generated by one column of the modular $S$-matrix of
$\mathrm{SU}(n)_k$ is, locally at a prime height $p=n+k$, a monomial ring whose valuations form a
numerical semigroup. This note asks how the columns fit **together**: the $p$-adic valuation of
the discriminant of the whole fusion ring splits into ramification, twice the sum of the column
defects, and twice a gluing term, and the only piece without a closed form is

$$\Delta(n,p)\;=\;\sum_{\text{orbits}}\delta(T).$$

Everything here is about that term — its distribution law, its mean, and the two classical objects
that sit at the ends of it.

## ⏱️ Thirty seconds

Every script runs on its own and prints what it measured. The cheapest one that shows the shape of
the whole thing:

```
python escalera_defectos.py
```

One row per numerical semigroup of small genus: one of genus one, two of genus two, four of genus
three. Those counts are the coefficients of $1$, $2/p$ and $4/p^2$ in the expansion, and the $3$
of $\Delta/b = 1 + 2/p + 3/p^2$ is $-1+4$.

Every script has its run saved beside it as `*_OUT.txt`, so any number the note calls *measured*
can be located without running anything.

## 🔗 `P3a.py` travels with this package

Seventeen of these scripts `import P3a`: the tool of Part I, which computes the order of one
column and its value semigroup. A copy is included here so that this package stands on its own —
a deposit that needs a second download is a broken deposit. It is the same file published with
Part I, [10.5281/zenodo.22848529](https://doi.org/10.5281/zenodo.22848529), unchanged.

## 🔍 Six scripts that audit the note, not the mathematics

These are the ones that found the defects, and they are shipped because a reader is entitled to
run them too.

| script | what it catches |
|---|---|
| `auditar_refs.py` | a citation without an entry, an entry never cited, a surname in the prose with nowhere to land, a figure or statement never referenced |
| `auditar_datos.py` | every cheap number recomputed from scratch; every expensive one located in the archived output of the script that produced it |
| `auditar_figuras.py` | each figure against its caption **in both editions**, and each figure newer than the script that draws it |
| `auditar_integracion.py` | the note against itself: the map in §1 against what each section delivers, no proof leaning on a later section, no statement left uninvoked |
| `auditar_latex.py` | a command whose backslash an escape has eaten — `\textsf` once became a tab, and LaTeX printed `extsf` and exited 0 |
| `auditar_tinta.py` | the text drawn **inside** the figures, against the numbers the note prints — a section number in an image is ink, and does not renumber itself |

## 🧾 What this package is, and is not

It is the material behind the numbers, kept so that nothing rests on a session that no longer
exists. It is **not** a library: each script is standalone, prints its own verdict, and exits
non-zero when it fails.

Two statements in the note carry no proof and say so where they appear — the trichotomy, and the
closed form for the gluing, which is verified rather than derived. The scripts do not hide that:
they are what the verification consists of.
